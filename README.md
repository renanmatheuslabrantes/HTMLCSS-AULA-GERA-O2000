# 🛒 Minha Loja — HTML e CSS

Projeto desenvolvido durante as aulas de **Desenvolvimento Web**, com o objetivo de praticar a construção de uma página de loja utilizando **HTML5 e CSS3**.

O projeto apresenta uma estrutura simples de e-commerce, com cabeçalho, menu de navegação, banner, seção de produtos, informações sobre a loja e formulário de contato.

## 📚 Objetivo do projeto

Este projeto foi criado como exercício prático para trabalhar conceitos fundamentais de desenvolvimento de páginas web, incluindo:

* Estrutura semântica do HTML;
* Organização de conteúdo com `header`, `nav`, `main`, `section` e `footer`;
* Links internos e navegação entre seções;
* Inserção de imagens;
* Formatação de textos;
* Criação e estilização de formulários;
* Uso de classes e IDs;
* Estilização com CSS;
* Efeitos de `hover`;
* Organização visual de uma página de loja.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura e conteúdo da página;
* **CSS3** — estilos, cores, espaçamentos, layout e formulário.


### `index.html`

Contém a estrutura principal da página, incluindo:

* Cabeçalho da loja;
* Menu de navegação;
* Banner de apresentação;
* Seção de produtos;
* Seção "Sobre a Loja";
* Seção de contato;
* Formulário de contato;
* Rodapé.

### `style.css`

Contém a estilização da página, como:

* Cores;
* Tipografia;
* Espaçamentos;
* Alinhamentos;
* Cartões de produtos;
* Botões;
* Formulário;
* Efeitos de interação.

## ▶️ Como executar

Não é necessário instalar nenhuma dependência.

1. Faça o download ou clone este repositório:

```bash
git clone https://github.com/renanmatheuslabrantes/HTMLCSS-AULA-GERA-O2000.git
```

2. Entre na pasta do projeto:

```bash
cd HTMLCSS-AULA-GERA-O2000
```

3. Abra o arquivo `index.html` em um navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para visualizar as alterações em tempo real.
